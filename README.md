# Blockbench-UV-Aligner

A poorly written Blockbench plugin to compensate for my inability to align UV maps. 

### Instalation

1. Download the latest release uv_aligner.js from [releases](https://github.com/ruairiwhite1/Blockbench-UV-Aligner/releases/tag/v1.0.0) 
2. Open Blockbench then select File followed by Plugins
3. Select Load Plugin from File
4. Select the uv_aligner.js downloaded from releases

### How to Use

1. Add Align UV to your toolbar
2. Select at least 2 cubes that share the same texture
3. Click Align UV
